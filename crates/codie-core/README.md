# codie-core

Core vocabulary shared by every codie crate: the stable error model
(`Error`, `ErrorKind`, `Result`) and the names of configuration locations.
No I/O, HTTP, terminal, or filesystem code lives here.

Status: **Phase 0 scaffold** — the agent loop, message model, and events
arrive in Phase 1.
