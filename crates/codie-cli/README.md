# codie-cli

The `codie` binary. Phase 0 ships only the clap surface for `--version`,
`--help`, and `-v` verbosity, with stdout reserved for program output and all
logs written to stderr.

Status: **Phase 0 scaffold** — prompts, print/JSON modes, subcommands, and
config loading arrive in Phase 1.
